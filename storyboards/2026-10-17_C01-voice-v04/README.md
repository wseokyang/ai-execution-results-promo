take01·02의 비교본도 보존한다. take01은 원본0~3.3초, take02는0~4.6초, take03은0~3.70초를 전체22초부터 배치했다. 말끝 보존은 ASR 외에 VAD/무음 검출을 참고해 여유를 뒀다. 속도나 피치를 바꾸지 않았다. 원본AAC 디코더의 float 초과값을 정수 중간 파일에서 잘라내지 않도록 파생 WAV는pcm_f32le다.

전체55초본은 기존1320개 영상 패킷을 그대로 복사했다. K04 밖 음성 내용은 유지하되 전체AAC는 재인코딩되므로 오디오샘플 동일성은 주장하지 않는다. 25초본은 미리보기 재인코딩이다. 원본MP4는 변경하지 않았다.

`technical_review.json`, `voice_trim_bounds.json`, 각 `edit_manifest_takeNN.json`에 근거를 보존했다. 직접 청취한 검수로 오인하지 않는다. take03 선택은 실제 사용자 답변에 근거하며 영상 전체 립싱크 승인으로 확대하지 않는다.
