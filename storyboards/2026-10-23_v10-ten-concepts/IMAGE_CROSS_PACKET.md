# 최종 이미지 교차·수정 재확인 패킷

세 독립 제출을 모두 받은 뒤 배포합니다. 88장 선택 PNG는 그대로이고 현재 `storyboards.json`, `scene_manifest.json`, `caption_proofs/`가 수정본입니다. 실제 제출 imagegen 프롬프트·아티스트 메모는 과거 이력이며 최신 PD 연속성 지시가 우선합니다.

## 독립 결과 요약

- A: 10연락판 88장, 원본 35장 확대 확인. 필수0, 제안2. I-A-001 C09 팔 받침대가 S07→08→09에서 이동; 고정 설정을 유지하면 향후 고정 필요. I-A-002 C10 K06 짧은 U와 K07 긴 U 사이 연속성은 상반신 전달 연결로 완화 가능. C10 S09는 같은 축이라 180도 반대 컷으로 설명하지 않도록 함.
- B: 88장 연락판+신규 원본22, 기존44는 앞선 독립 단계 개별 확인. I-B-001 필수: C10 실제 P1 이동은 후경→카메라 방향인데 반대 지시. I-B-002 필수: C09 바닥 고정 설정과 실제 받침대 위치 불일치. I-B-003 필수: C06 K09/C07 상단 큐/C09 상단 큐/C10 K02·03·05·06·09 얼굴 가림. PNG 재생성 없이 문구·좌표 수정 가능. 실제 HTML 렌더 검수가 아닌 PNG와 CSS 대조였음.
- C: 88장 연락판+원본20. I-C-001 필수: C10 K07~09는 MC왼쪽/DV오른쪽 같은 축, 후경입구→전경발표 위치로 정합. I-C-002 필수: C10 K03 오른쪽 패치로 가위를 이동하는 수정이 screen에는 있으나 next_motion/scene_list에 누락.
- PD: 실제 HTML C10 엔딩에서 세 얼굴 가림 확인 I-PD-001. 추가 원본+자막 합성 정지 시 C04 K04 얼굴 가림도 발견.

## 적용한 처리

1. C10 K07~09 같은 축/후경입구→카메라쪽 전경 발표 위치로 상위 연속성, 시작 상태, 화면, next_motion, scene_list, units, manifest 동기화. K03도 모두 동기화.
2. C09 두 의전 팔은 이동식 받침대로 정의. 컷 사이 준비·재배치 생략, **한 숏 안에서는 시작 PNG의 위치 고정/순간이동 금지**. 이미지 실제 제출 프롬프트는 수정하지 않고 manifest의 pd_continuity_override에 최신판단 명시.
3. C10 K06은 손전달 상반신 연결로 짧게 사용, 전체 리본 길이는 K07 기준. 길이 변형 생성 금지.
4. 컷별 자막 폭·위치·글자 크기 변경. C10 초중반은 가운데 빈 벽, K06은 별도로 left39/width28. C07 하단. C06/C07/C08/C10 마지막은 동작 뒤 하단 제목판. C09 상단 중앙 좁은 박스. C04 K04는 태블릿 빈 화면 내 정보판, 실제 영상은 원근 추적 필요.
5. `caption_proofs/C01_captions.jpg`~`C10_captions.jpg`는 모든 큐의 정지 합성 증빙. PIL 글꼴 지표는 브라우저와 미세 차이 가능하므로 root가 실제 HTML도 확인. 원본 PNG 불변. 실제 동작 가독성 검증 아님.

## 요청

다른 두 검수자 지적별 동의/이견/보완을 근거와 함께 반환하고, 수정본·실제 자막 증빙 10연락판을 열어 해결/미해결/제안 상태를 각각 확인해 주세요. 새 필수 문제가 없으면 선택용 콘티 단계 완료 가능 여부를 명시합니다. 실제 관객 반응·Flow 동작·최종 영상 검증이라고 하지 않습니다. 파일 수정 없이 반환.
