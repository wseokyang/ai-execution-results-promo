# Q-AI Fair · 10안 선택용 V10

2026-10-23 최신 사용자 요청: 기존 1~5안을 영상 제작 전에 다시 다듬고 새로운 5안을 추가한다. 사용자가 총 10안에서 고른다. 캐릭터 외형도 안별로 겹치지 않게 다양화한다.

- 영상 제작 도구는 후속 Flow. 자막·정확한 화면 글·행사명은 총괄이 후편집으로 넣는다. 이번 작업에서는 Flow 업로드·생성·계정 조작·크레딧 사용·영상/음원 렌더를 실행하지 않는다.
- 소음 환경이므로 화면+자막만으로 이야기와 행사의 연결을 이해해야 한다. BGM·효과음은 웃음의 보조다. 대사나 립싱크를 이해의 필수 조건으로 만들지 않는다.
- 행사명은 Q-AI Fair. AI 실행 사례와 경험을 나누는 행사라는 의미를 유지한다. 세부 일정·장소·신청·시상·성과 수치는 미확인이다. 허구의 장면을 실제 참가자의 성과처럼 제시하지 않는다.
- 기존 5안의 승인된 핵심 설정과 인물을 보존하되, 동기·인과·설명 길이·반전 선공개 문제는 수정한다. 새 5안은 C06~C10으로 번호를 이어 붙인다. 이는 최신 요청에 따른 기존 C01~C05 규칙의 범위 확장이다.
- 새 안은 기존 성공 자세 교정/카메라 체포/사무실 배송/트로이목마 급식/기둥 된 괴수의 배경만 바꾼 변형이 아니어야 한다. 장르 약속, 주인공의 욕망, 사건을 키우는 선택, 마지막 후폭풍을 구분한다.
- 돌고래유괴단은 단일 공식이 아니다. 실제 참고 광고에서 확인한 이야기 작동 방식을 응용한다. 장면·대사·음악·캐릭터를 복제하지 않는다. 참고 자료 열람 범위와 창작적 해석을 구분한다.
- 캐릭터는 나이·체형·얼굴형·머리·복장·자세·감정의 조합으로 안별 실루엣을 다르게 한다. 외모 자체를 웃음의 대상으로 삼지 않는다. 같은 젊은 남녀 기본 얼굴을 반복하지 않는다.
- 총길이 60초 이하, 짧은 자막 한 번에 하나를 기본으로 한다. 반전 행동을 자막으로 먼저 설명하지 않는다. 첫 프레임은 동작 전 상태, 정확한 글은 별도 합성층이다.
- 새 5안 모두 실제 씬별 첫 이미지까지 제작한다. 기존 5안 이미지는 변경된 내용에 맞는 경우 재사용하고, 필요한 컷만 새 버전으로 교체한다. 이미지 수와 향후 Flow 요청 수는 별개다.
- 원본 V9·이전 영상·qrew 자료는 변경하지 않는다. 기존 C03 영상은 재사용 우선이다. 정지 이미지 검수는 영상 동작 성공, 관객 반응 또는 실제 상영 가독성 검증이 아니다.

검수는 세 명이 같은 종합 기준으로 10안 전체를 독립 검토하고, 첫 제출 후 서로 교차 검증한다. 이미지도 실제 파일을 열어 같은 절차로 확인한다. 필수 수정과 취향 제안을 구분하고 총괄의 채택 이유를 기록한다.
