# Flow와 후편집의 역할

이번 버전은 10안 중 사용자가 고르기 위한 콘티·첫 프레임 패키지다. Flow 요청은 하지 않는다. 기존 예약도 PAUSED 상태임을 확인했고 재개하지 않았다.

## Flow에서 만들 것

선택된 안의 깨끗한 실사/특촬 동작 영상. 지정 첫 프레임, 인물·옷·공간·소품의 연속성, 동작 전후 상태를 중심으로 요청한다. 자막, 행사명, 정확한 한국어 문서·화면, 대사·내레이션·립싱크는 생성 요구에서 제외한다. 대사가 없어도 모든 장면의 의미가 전달되게 설계한다. 실제 모델·비용·계정 잔액은 이후 요청 직전에 확인한다. 현재 계정 수와 크레딧을 확인한 것으로 쓰지 않는다.

한 제작 단위의 동작이 8초 생성물 안에 들어가더라도 본편에서는 필요한 부분만 사용한다. 같은 씬의 복잡한 동작은 시작 상태를 나눠 계획하고, 앞 컷에서 채택한 끝 프레임이 뒤 컷의 기준 이미지보다 연속성에 적합하면 그 끝 프레임을 우선한다. 이미지 수는 성공 영상 수나 최종 요청 횟수가 아니다. 특히 C05의 K02A·K02B는 하나의 7초 편집 구간(4–11초)을 나눠 채우는 두 시작 상태이며 각각 7초씩 사용하는 뜻이 아니다. 전체는 87편집 컷·88시작 상태다.

## 후편집에서 넣을 것

- 모든 자막·행사명·정확한 화면 글은 별도 층으로 추가한다. JSON의 caption_cues는 안별 절대 시간이며, box는 16:9 화면에 대한 백분율 위치다. 실제 동작에 맞춰 최종 진입·퇴장 시간을 조정한다.
- 자막은 소리를 대신하는 정보다. 이미 보이는 몸개그를 매번 해설하지 않고, 인물의 목표·판단을 바꾸는 한 문장에 집중한다. 반전 결과는 화면이 먼저 공개한다.
- BGM·효과음은 선택적인 보조다. 음악을 꺼도 인물의 선택과 결과가 이해되어야 한다. 기존 음성은 필수 전달을 맡지 않는다.
- 표정·손·핵심 물체가 움직이는 경로를 자막으로 덮지 않는다. 정지 미리보기 뒤 실제 영상에서도 가림과 읽기 시간을 재검수한다.
- 마지막 Q-AI Fair와 연결 문구를 읽을 시간을 확보한다. 확인되지 않은 날짜·장소·혜택·신청 링크는 넣지 않는다.

## 기존 5안의 합성 메모

C01은 포스터와 실제 원본 자세를 맞추고 K04를 K03 모니터 면에 합성한다. 기존 질문 반복을 코치의 한 번의 주장으로 바꿨고 K02 비교를 2.5초로 줄였다.

C02는 AI 후보 선택과 사람의 비교·재촬영을 구분한다. K07 실제 채택 촬영 순간을 휴대전화 화면과 K08/K09 인화사진에 똑같이 합성한다. 사진 속 손 자세 차이를 새 원본 생성으로 억지 해결하지 않는다.

C03은 기존 영상·원본을 먼저 재사용한다. 새 시작 이미지가 기존 영상을 전부 재생성하라는 지시가 아니다. 기록 라벨은 ‘잘됐던 작업 기록’과 ‘시행착오 기록’. 기존 구형 ‘내 작업 기록’은 새 편집 버전에서 교체한다.

C04는 K04를 5초로 줄인다. 작은 ‘AI 대조 · 확인 필요’ 머리말과 ‘탑승자 없음 ↔ 수저 요청’을 하나의 정보 덩어리로 구성한다. 원문 확인 뒤 실제 병사 행동을 보여준다. 첫 배식창 공개 이전에 그릇과 숟가락을 노출하지 않는다.

C05는 입구를 자기 몸으로 막으려던 양팔이 지붕 지지대로 바뀐다. K02A 기둥 제거 끝 프레임을 K02B 시작에 우선한다. K07의 주둥이 왼쪽·귀 오른쪽·S목 방향을 유지한다. 이어컵 실체→‘들리세요?’ 자막→엄지 응답 시도 순서라 실제 음성을 들을 필요가 없다.

## 새 5안의 동작·합성 메모

C06은 ‘야근 전체를 AI로 즉시 해결’하는 이야기가 아니다. 한 사례에서 배운 분류 방법을 실제 문서 한 묶음에 적용하고 사람이 원문을 대조한 뒤 퇴근한다. 유령은 확인이 끝나기 전에 베개를 꺼냈다가 기다린다. 마지막 방문 유령의 접이식 의자 펼치기는 첫 유령의 휴식 목표를 다시 방해한다.

C07의 밧줄은 빈 바닥에 놓인 초대 표시다. 몸에 감거나 상대를 강제로 끌지 않는다. 총잡이가 상대와 빈 자리를 가리키고 상대가 자발적으로 함께 걷는다. 도착 후 질문자들이 다시 시야를 가리고, 총잡이가 틈을 찾아 배우는 쪽으로 바뀐다. 마지막 연필 묘기 실패는 목소리 없이도 읽히는 짧은 행동으로 사용한다.

C08의 금빛 앞면과 작업 기록이 있는 뒷면은 동일한 회전 무대 구조다. 결과·과정의 구체적인 도해는 무지 판 위에 후합성한다. 고정된 좌상 조명 때문에 기록판에 반사가 생겼다가 망토의 검은 안감이 빛을 막아 사라져야 한다. 주역의 거대한 몸이나 외모가 아니라, 자신이 다시 주목받았다고 믿는 표정과 실제 보조 역할의 차이가 웃음이다.

C09는 손바닥을 펴는 동작이 자료 전달 장치를 작동시키는 규칙을 먼저 보여준다. 장치 팔은 총 2개, 한 번에 한 팔만 움직인다. S01~S07 시작에는 얼굴이 투구에 가려진다. 투구를 벗은 뒤 사람의 노트는 원래 위치에 남고, 투구 안에는 마지막 얇은 낱장 묶음만 들어간다. 마지막에 꺼내는 것도 그 낱장이다. 후편집에서는 결과물·작업 노트·수정 기록을 색과 짧은 라벨로 구분한다.

C10은 처음 5초 안에 절단→자동 복구를 보여준다. 기계에 붙은 얕은 도구 받침 위의 두 가위를 묶는 조각은 이미 잘린 짧은 별도 조각이며, 바닥의 긴 본선 리본과 이어지지 않는다. 줄넘기로 바뀌기 전 기둥·공급구에서 긴 리본을 분리하는 시간은 컷 사이에 생략한다. 첫 발표자만 한 번 크게 넘고 실제 작업 기록을 펼친다. 다음 발표자의 무릎 풀기는 두 번째 점프를 생성하지 않고 후폭풍을 남기는 장면이다.

새 5안의 편집 길이는 C06 44초, C07 43초, C08 41초, C09 45초, C10 46초다. 계획한 시작 상태는 각각 9·9·8·9·9개이며 총 44개다. 기존 5안의 44개를 합친 88개 시작 상태는 10안 선택용 자료이고, 88회 생성 성공이나 정확한 최종 생성 횟수를 뜻하지 않는다.

## 검수 한계

콘티와 정지 시작 이미지는 제작 계획이다. 실제 동작·입 모양·후반 합성의 완성, 현장 화면에서의 가독성, 관객의 웃음 반응을 검증한 것으로 쓰지 않는다. 새 영상 제작과 최종 편집 뒤 별도 확인한다. 기존 원본과 완료 영상은 덮어쓰지 않는다.
