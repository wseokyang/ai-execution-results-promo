# V10 총괄 수정 판단

기존 다섯 이야기의 승인된 핵심을 보존하고 다섯 이야기를 추가한다. 검수 점수는 편집 판단이며 실제 관객의 웃음이나 선호를 측정한 결과가 아니다.

## 상세 텍스트 검수 반영

| 지적 | 처리 | 이유 |
|---|---|---|
| A-001 / C-001 | 주 리본과 이미 잘린 접착 자투리를 분리. 두 가위는 자투리에 붙어 트레이에 남음. | 줄넘기 리본에 가위가 함께 매달리는 연결 오류를 없앤다. |
| A-002 / B-002 | C09 마지막 자료를 얇은 종이 한 장으로 통일. 원래 수첩은 책상에 남음. | 전달되지 않은 새 물건이 투구에서 생기지 않는다. |
| A-003 / B-004 | C04 final_action을32–36.8초로 동기화. | 실제37초 본편과 일치. |
| B-001 / B-I01 | C03 같은 입력기호와 다른 확인·수정 순서를 양쪽 페이지에 합성하는 정확 도식 지정. | ‘단서가 있다’는 자막 주장을 화면 비교가 받친다. 허구 기호이며 성과 숫자를 만들지 않는다. |
| C-002 / C-I01 / B-I02 | C05 K06→K07 높이 조절·고정·등반 시간 생략 명시. | 기존 PNG를 보존하면서 사다리 상태 변화가 컷 사이에 있었다고 연결. 실제 연속 동작 성공을 주장하지 않는다. |
| A-004 / B-003 / C-003 | C10 절단3초, 복구와 사회자 눈 반응을5초 안에. 기술 자막은4.7초 이후. | 평범한 개막식이 이상해지는 사건을 먼저 보인다. B는 필수 훅정합성, A/C는 개선으로 판단했으나 모두 채택. |
| A-005 / B-006 | C06 설명 구간 압축, 쿠션을 대고 미리 쉬려다 멈추는 행동과 ‘이 한 건만 확인하면 끝.’ | 유령의 휴식 욕망이 설명 구간에서도 행동으로 이어진다. |
| A-006 / C-005 | C08 회전·과정 구간 압축, 주역이 객석 정면을 다시 차지하려 이동. | 공간 전환 중에도 인물의 욕망이 보인다. |
| A-007 / B-005 / C-004 | C07 줄 준비 압축, 한 사람만 부르는 손짓, 도착한 질문자들이 다시 시야를 가림. | 독점하려는 선택이 더 불편한 맨 앞자리라는 결과를 만든다. |
| B-007 | C09 첫 결과판 수여 중 인간 시선은 뒤 기록으로 향함. | 사절의 위엄과 관심의 엇갈림을 일찍 시작. |

새 다섯 안의 편집 길이는 C06부터 **44 / 43 / 41 / 45 / 46초**. 시작 상태44개는 유지하며 준비 동작의 대기를 줄였다. 별도 생성 원본의 길이를 이 수치로 가정하지 않는다. 이미 완료된 원본이나 영화를 이 스크립트가 수정한 것은 아니다.

## 추천 판단

참석 독려는 C06: 사람을 내보내려던 유령의 목적 때문에 사례를 배우러 가며, 성공 직후 상담 대기라는 새 문제가 생긴다.

현장 개막은 C10: 의식 자체에서 고장이 생겨 새 입장 의식이 되고, 발표자가 기록을 펴는 행동으로 실제 진행에 연결된다.

C07/C08은 코미디 밀도에 대한 초기 점수가 상대적으로 낮았다. 이야기 폐기 대신 절차를 줄이고 주인공의 시야·위치·체면을 되찾으려는 선택을 보강했다. 최종 선택은 사용자가 실제 콘티를 보고 한다.


## 최종 이미지 독립검수 반영

- I-B-001 / I-C-001: C10 입장축을 후경 입구→카메라 쪽 전경으로 통일. 180도 반대 컷 설명은 채택하지 않음.
- I-C-002: C10 K03 가위를 오른쪽 패치로 짧게 옮기는 지시를 shots, scene_list, generation_units, manifest에 동기화.
- I-A-001 / I-B-002: C09 의전 팔을 재배치 가능한 받침대로 설정. 컷 사이 준비 생략, 한 숏 내 받침대 고정. 실제 제출 이미지 프롬프트는 역사로 보존.
- I-A-002: C10 K06은 상반신 손전달 중심으로 짧게 연결하고 리본 전체 길이는 K07 기준. 길이 변형 동작 요청 금지.
- I-B-003 / I-PD-001: 신규 컷별 자막 좌표·글자 크기를 실제 이미지에 맞춰 수정. C10 가운데 벽, C07 하단, C06/C07/C08/C10 마지막은 동작 이후 하단 제목판. 업로드 PNG 원본은 불변.
