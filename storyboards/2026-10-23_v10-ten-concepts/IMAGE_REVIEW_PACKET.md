# 실제 이미지 검토 안내

완료된 이미지 목록의 기준은 `scene_manifest.json`이다. `images` 폴더의 수정 전 파일까지 모두 채택본으로 세지 않는다. 이 파일은 작업 지침이며 검수 완료 주장 자체가 아니다.

세 검수자 모두 10안 전체를 같은 종합 기준으로 독립 확인한다. 실제 파일을 열어 인물·소품·공간·동작 직전 상태·자막 자리·화면의 웃음·안별 차이를 확인한다. `contact_sheets`의 안별 모든 시작 상태를 먼저 보고 불분명한 손·소품·공간은 원본을 연다. 실제 연 파일과 연락판 확인 범위를 구분한다. 원본 개별 확인이 필요하면 망설이지 말고 확인한다.

기존44장의 직전 B/C 검토는 `existing_image_review.json`, 텍스트 교차와 재확인은 `text_review.json`이다. 첫 독립 이미지 제출 전에는 다른 검수자의 **신규 이미지 의견**을 읽지 않는다. 이미지에는 자막을 굽지 않았으며 `index.html` 버튼은 별도 후편집 위치 미리보기다.

특히 확인할 제작 연결:

- C01 포스터→실제 원본, 의자·매트, 사고 뒤 코치의 권위 유지. 모니터 합성은 후속 단계.
- C02 동일 가림 위치, 수갑 전후, 같은 촬영 순간의 휴대전화/인화사진 후속 합성.
- C03 두 사무실/파일, 입력 공통기호와 다른 확인·수정 순서 후속 합성. 기존 MP4를 재생성한 작업이 아님.
- C04 닫힌 세 창→공개, 병사·그릇 수, 지휘관 숟가락은 마지막 행동 전에는 숨김.
- C05 S자 목/양손 지붕 지지/귀·주둥이축. K06→K07 높이 조절 시간 생략을 반영하며, 사다리 연속 변형을 요구하지 않음.
- C06 거꾸로 유령의 정상 목, 서류 손잡이를 걸기 전, 쿠션 소유, 새 유령·노트북·접이식 의자 등장 시점.
- C07 개별 4인, 줄은 손으로 느슨하게 잡고 몸에는 걸리지 않음. 기존 연필과 빌린 볼펜 구분. 빈자리 독점→군중이 다시 가리는 동선.
- C08 주역의 얼굴·망토 안팎, 지휘자/제작자 구분, 회전 세트의 앞뒤, 좌상단 광원→화면 반사→검정 안감 차광의 공간 관계.
- C09 두 팔 중 하나만 작동, 실제 받침대의 자료 종류/수량, 손바닥 호출, S07 시작에는 얼굴 비공개, S08/S09 보라 얼굴 동일, 투구가 자료 원통이 되는 실제 물성.
- C10 반전 전후 리본 상태, 실제 공급 롤, 별개 절단 자투리와 가위의 트레이 잔류. 주 리본은 독립된 자유 끈. MC/DV/첫·다음 발표자 외형, 점프 전 상태와 착지 후 상태 구분.

필수 오류에는 안·씬·실제 이미지 경로·근거·구체 수정을, 취향에는 개선 제안으로 표시한다. 정지 검수로 Flow의 실제 동작 성공·관객 반응·현장 가독성을 검증했다고 하지 않는다. 결과 수집 뒤 동료 지적을 교차하고 실제 수정된 파일을 다시 확인한다.
