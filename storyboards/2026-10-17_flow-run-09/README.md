# K06 질문 음성 수정 · run09

사용자가 지적한 ‘다음 사례도 볼까요?’ 발음을 수정하기 위한 음성 소스다. [성공한 원본 MP4](C01_K06_D_voice_take02.mp4)는 재인코딩 없이 보존했다. 8초,1280×720,24fps,AAC 오디오 있음. 다운로드 파일과 보존본 SHA256 일치.

사용자 수동 실패와 새로고침 뒤 보안 연결 오류 표시가 사라졌음을 확인했다. 총괄 첫 Lite10 요청은 접수됐으나 오디오 생성 실패로 환불됐다. 긴 영어·발음기호 지시를 간결한 한국어 지시로 수정한 두 번째 Lite10 요청은 성공했다. 실제 잔액은 20→10→20→10, 순사용10. 실패한 take01의 원본은 없으며 성공 take02만 원본1개다. 무음 반환OFF 유지, 추가 재시도 없음.

생성ID `c72a6cb0-6acf-40ec-8976-29be10c5315d`. 생성·프롬프트·모델·이미지·차감·환불·다운로드 기록은 `generation_log.json`에 있다. 이번 성공으로 로컬 원본은 총15개(동작11+K04음성3+K06음성1)다.

자동전사·VAD·디코딩은 검사했지만 실제 청취는 아니다. ASR은 ‘사료도’로 인식했으며 발음 개선 확정으로 보고하지 않는다. [v07 36초 수정본](../2026-10-17_C01-voicefix-v07/README.md)에 새 음성을 넣어 청취 판단을 요청했다.
