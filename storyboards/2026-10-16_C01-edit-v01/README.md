# C01 · 왜 이제 알려주셨어요 · 55초 검토용 편집본

[검토용 MP4](C01_review_edit_v01_55s.mp4). 1280×720, 24fps, 영상 55초(컨테이너 약55.02초). 일곱 동작 컷은 모두 실제 Flow 영상이다. 원본을 변경하지 않고 별도 렌더했다.

현재 상태는 **시각 검수 통과 후보, 음성·립싱크 확인 대기**다. 최종 완성본으로 승인하지 않았다. 사용자가 재생해 발음과 임시 더빙을 확인할 수 있도록 전달했다.

| 구간 | 입력 |
|---|---|
|0–6|run06 K01 take02|
|6–14|run06 K02 take02|
|14–21|run06 K03 take02|
|21–27|run05 K04 take02|
|27–34|run04 K05 take01|
|34–42|run05 K06 take01|
|42–49|run05 K07 take01|
|49–55|직전 K07 마지막 포함 프레임(167번) 정지 + 기존 행사 타이틀 디자인|

K02는 자동 전사상 마지막 말이 5.96–7.98초에 걸려 8초 전부 보존했다. K07은 마지막 말이 자동 전사상6.12초까지이므로7초를 사용했다. 정확한 턱 밑 유지 동작 대신 몸 앞에 양동이를 준비하는 콜백으로 PD 변경을 명시한다.

K04 화면 밖 D 대사 “제가 헤맨 과정도 같이 보여드릴게요.”는 Windows Microsoft Heami Desktop으로 만든 **임시 더빙**이다. 원본 WAV는3.629초, 편집본22.000–25.629초에 배치했다. 보이는 인물의 입에 맞춘 대사가 아니다. K06 D와 목소리 일관성·자연스러움은 청취 확인 대기다. 다른 컷은 원본 오디오를 보존해 음량을 조정했다. 새 BGM은 추가하지 않았다.

자동 전사는 청취나 발음 판정을 대신하지 않는다. K02 “진작/진짜”, K06 “사례/사료”, K05 끝의 추가 음절, K02 원본 말끝과 전체 립싱크가 확인 대상이다. 오류로 확정해 재생성하지 않는다.

검수자는 세 명 모두 실제 렌더 추출 이미지를 확인했다. 행사명·안내 자막에 오탈자·잘림이 없고 엔딩6초를 확보했다. 컷 경계 표본과 전체 파일 디코딩은 통과했으며 연속 재생·실제 청취 승인을 뜻하지 않는다.

- `edit_manifest.json`: 입력 원본 체크섬, 타임라인, PD 수정
- `render_review.py`: 재현 가능한 편집 코드
- `render_validation.json`: 메타데이터·디코딩 결과
- `edit_contact_sheet.jpg`, `review_frames/`: 실제 렌더 추출 표본
- `review_summary.json`: 세 명의 독립·교차 검수 및 재확인

공개 게시하지 않았다. 원본·기존 전달 패키지·원자료는 덮어쓰지 않았다.

사용자 후속 확인: K02와 K06의 지정 대사·말끝은 자연스럽게 들린다고 직접 확인했다. K04 Heami 목소리는 교체 요청했으며 v02 폴더에서 대체 작업을 진행한다. 이 답변을 전체 립싱크 승인으로 확대하지 않는다.
