# C03 화면·자막 편집 v04

`C03_Q-AI_Fair_edit_v04.mp4` — 44.75초, 1280×720, 24fps, 1074프레임. 오디오 트랙이 없는 무음본이다.

기존 v03의 13개 편집 구간을 같은 길이와 순서로 다시 합성했다. 모든 화면의 움직임은 기존 실제 생성 원본에서 왔다. 정지 이미지로 동작을 대신하지 않았다. 기존 음성과 BGM을 모두 제거했다. 이번 요청에 필요한 인과 수정은 후처리 자막과 도해로 해결했으며, 새 원본 생성이 필요한 필수 누락은 찾지 못했다.

- 첫 요청을 ‘결과와 과정, 빠짐없이 보내주세요.’로 명시했다.
- 첫 모듈은 ‘잘됐던 작업 환경’, 두 번째는 ‘안 됐던 작업 환경’으로 구별했다.
- 장갑 장면 위에 있었던 ‘이건 왜 보냈어요?’를 없앴다. 20.8–24.8초에 ‘보낸 동료’ 화자를 표시해 과잉 배송의 이유를 전달한다.
- K03 노트북에는 기준·이번 결과의 같은 기호를 합성했다. K06은 ‘잘됐던 작업 기록’과 ‘시행착오 기록’을 정확하게 표기하고, 같은 입력기호 및 서로 다른 확인·수정 순서를 보여준다. 허구의 설명 도식이며 실제 성과나 일반적 원인을 입증하지 않는다.
- Q-AI Fair와 ‘AI 실행의 과정까지, 함께 봐요.’를 38.75–44.75초 상단에 유지했다. 마지막 제목은 V11의 44.55초 종료보다 0.2초 연장해 마지막 프레임에서 사라지는 현상을 피했다.

제작 기준은 V11 `storyboards.json`의 C03 `shots.caption_cues`와 `text_assets`, `scene_manifest.json`의 장면별 인물·소품 기준이다. 실제 영상 편집 구간과 종이·모니터 합성 좌표는 `2026-10-20_C03-edit-v03/render_edit.py`를 재사용했다. 원본 기획·이미지·영상은 수정하지 않았다.

`render_caption_v04.py`는 자립 재현 코드다. `build_renderer.py`는 기존 v03 코드에서 이 코드를 만든 변환 기록이다. `verify_preservation.py`는 역사적 v03 해시·편집 구간 검증과 요약 연락판 생성 코드다. `edit_manifest.json`, `technical_validation.json`, `C03_captions.srt`에 출처·구간·문구·검증을 기록했다. Windows Python 경로와 외부 로컬 의존성은 코드에 명시했다.

실제 최종 MP4에서 추출한 연락판 `review_contact_01.jpg`부터 `09.jpg`까지 전부 열어 컷 순서와 자막 등장·소멸 경계, 장갑 구간, 파일 집기·비교·퇴장·기사 착석을 표본 검토했다. 1/11/22/27/29/40초의 1280×720 PNG도 직접 열어 자막·도해·파일 라벨·엔딩을 검수했다. `review_overview.jpg`는 16개 표본의 요약이다. 얼굴·노트북 비교 도식·파일 라벨은 가려지지 않는다. K05 하단 자막은 테이블과 파일 아래 일부를 지나가지만 파일 집어 올리기와 주황 파일의 위치는 표본상 식별된다.
