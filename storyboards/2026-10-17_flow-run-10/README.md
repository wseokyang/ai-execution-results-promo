# C05-F06 동작 영상 · run10

C01 v07의 새 질문 음성을 사용자가 선택한 뒤, 다음 제작 순서인 C05의 미생성 F06을 진행한다. 남은 실제 잔액 10으로 기존에 지정한 단순 동작 Lite 후보를 선택했다. 패키지의 Fast 기본값과 다른 실행 모델을 기록한다.

입력: C05-N03.png / C05-F06_motion_only.txt. 고정 와이드에서 직원의 질문 동작에 귀신 셋이 눈치를 보며 자신감을 잃는다. 세 귀신의 손은 계속 내려 두며 지목 릴레이를 시작하지 않는다. C의 운동복과 신발은 흰 천으로 가린다. 직원의 “그런데, 직접 해본 사람은요?”는 후편집 대사다.

현재: 첫 Lite10 요청은 오디오 생성 실패로 환불됐다. 동작 전용 컷이라 무음 반환을 켠 기술 재시도 1회가 성공했다. 실제 잔액10→0→10→0, 순10사용. Lite / 8초 / 720p / 16:9 / Frames 시작만 / x1. 성공 ID `c0bf916b-18c5-4a75-a9c5-9596fb03e89e`. 무음 반환은 결과 확인 후 OFF로 복구했다.

사용자 저장 완료 후 [8초 원본 MP4](C05-F06_take02.mp4)를 재인코딩 없이 보존했다. 1,772,314bytes, 1280×720,24fps,192프레임. 다운로드와 보존본 SHA256 일치, 영상·오디오 디코딩 통과. 보존 원본은 총16개다. 원본에는 AAC 48kHz 스테레오와 0이 아닌 오디오 신호가 있으며, 무음 반환 ON이 실제 무음 출력을 뜻하지는 않는다. 실제 청취는 수행하지 않았다.

원본 와이드에는 0.5초 무렵부터 네 번째 귀신이 나타나므로 그대로 채택하지 않는다. [6초 크롭 시각 후보](C05-F06_crop_review_6s.mp4)는 원본0~6초에서 x0,y40,w960,h540을 잘라1280×720로 구성한 별도 파생본이다. 직원과 기존 A/B/C만 보존한다. 원본은 변경하지 않았다. 크롭본 오디오는 시각 검토용으로 제외했으며 직원 대사는 후시녹음이 필요하다. 최신 검수 판정은 review_summary.json을 따른다.

세 검수자 A/B/C가 독립 검토와 상호 교차 검증을 마쳤고, 크롭본0~6초를 시각 후보로 채택했다. 실제 수정 렌더의13개 전체 구도 표본과144프레임의 오른쪽 경계 띠를 확인했다. 추가 귀신의 잔여물·새 필수 잘림은 발견되지 않았다. B의 작은 손 올림은 지목이 아닌 당황한 반응으로 수용한다. 전체 연속 재생·실청취·립싱크 검증으로 확대하지 않는다.

성공 요청을 중복 제출하지 않는다. C05는9개 계획 컷 중1개 시각 후보를 확보했으며, 다음 컷은 실제 잔액 갱신 후 C05-F01부터 기존 미생성 순서를 따른다. 전체41개 중8개 계획 컷에 후보가 있고33개는 미생성이다. C05 전체 완성본은 아직 아니다.

제출 프롬프트는 C05-F06_take01_prompt.txt와 C05-F06_take02_prompt.txt에 UI 입력 그대로 보존했다.

take02 프롬프트도 별도 보존했으며 문장 변경 없이 무음 반환 설정만 바꿨다. 두 파일의 마지막 빈 줄은 실제 UI 입력을 보존한 것이므로 `git diff --check`의 blank-at-EOF 예외로 남긴다.
