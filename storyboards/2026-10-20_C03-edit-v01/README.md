기존 Flow 원본만으로 만든 1280×720, 24fps, H.264/AAC 검토본이다. 실제 동작 영상 10개 편집 구간으로 8개 씬을 연결했다. 추가 영상 생성·크레딧 사용은 0이다. 기존 18개 생성 원본은 바꾸지 않았다.

사용자는 필요한 경우 한 컷 추가 생성을 허용했다. 현재 편집에서 꼭 필요한 미생성 컷은 발견하지 못했으므로 추가 요청은 제출하지 않았다. 새 계정이나 크레딧 잔액도 이번 편집 작업에서 조회하지 않았다.

장갑 벗기 과정은 생략하고 맨손·빈 장갑의 완료 상태를 보여준다. 두 번째 배송 뒤에는 실제 커프 정돈 동작을 연결한다. 이 편집을 전체 장갑 삽입·탈착 성공으로 기록하지 않는다.

전화 질문은 run01 K05의 2.4–4.2초 음성을 전체 20.15초부터 사용했다. 전화 답변은 run02 VO의 0–2.7초 음성을 전체 22.25초부터 사용했다. 화면은 전화기·파일 오류가 없는 run03 K05의 뒤·옆모습이다. 대사 배속이나 새 음성 합성은 없다.

K03 노트북에는 같은 세 칸의 참고·실행 결과 도식을 합성했다. K06에는 펼친 주황 파일 내부 기록과 탁자 위 회색 파일의 내부 기록을 연결하는 비교 표시를 26.75–28.50초에 넣었다. 기록의 숫자·실제 성과는 만들지 않았다. 두 도식의 합계 노출은 가독성을 위해 기존 원안의 약 3초에서 4.25초로 조정했다.

K06의 파일 모으기에서 K07의 이미 안고 있는 상태로 넘어가는 부분은 시간 생략이다. K08은 퇴장과 기사의 착석을 모두 보존한다. 행사명과 참석 권유 문구는 40.25–45.25초에 고정한다. 미확정 날짜·장소·신청 방법은 넣지 않았다.

## 음향

원본 대사·현장음을 사용하고, 짧은 새 금관·비브라폰 화음과 작은 천 마찰 효과만 추가했다. 실패 환경의 설명과 발견 장면에는 새 음악을 비웠다. 과거 C01 음악·기존 곡·데모 MIDI는 사용하지 않았다. 악기 음원 출처와 라이선스는 `score_sources.json`, `GeneralUser-GS-LICENSE.txt`에 있다. 노트와 편집 코드를 함께 보존했다.

기술 검사는 전체 디코딩, 1,086 영상 프레임, 원본 해시 보존, 최종 스테레오 PCM 포화 여부를 확인한다. 자동전사는 실제 청취가 아니다. 원본 감사 중 확인한 16kHz 모노 다운믹스 피크를 원본 스테레오 클리핑으로 해석하지 않는다.

## 검수와 남은 확인

세 검수자의 독립 검토·상호 교차 검증·수정 확인은 `review_summary.json`에 기록한다. 검수는 실제 렌더에서 추출한 화면 표본을 대상으로 한다.

최종 완성 승인 전에는 전체 재생에서 한국어 발음, 질문 장면의 입 움직임과 음성 연결, 음량·음색 및 전체 호흡을 확인해야 한다. 표본과 ASR만으로 실제 청취·립싱크 통과를 선언하지 않는다. 현재는 첫 전체 검토본이며, 새로운 필수 생성 컷이 있다는 판정은 없다.

`render_edit.py`로 재현할 수 있다. `C03_picture_v01.mp4`, 믹스 WAV 등 재생성 가능한 로컬 중간 파일은 Git에서 제외하고, 최종 검토 MP4·표본·편집 원장·음원 출처·코드는 추적한다.
