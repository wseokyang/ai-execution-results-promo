# Q-AI Fair 상영 스타일 보완 V15

최신 동작·컷 순서·길이를 보존한 2·3·4·5·6편의 파생 편집본입니다. 원본 및 기존 V13/V14는 수정하지 않았습니다. [영상 모아 보기](index.html)

- 공통 행사명: Q-AI Fair / 품질팀 AI 성과 교류회.
- 본문 맑은 고딕 Bold 42px 유지. 엔딩 제목68–72px, 행사 설명34–36px.
- C03 발견 자막을 안전영역 안쪽으로 이동. 엔딩 설명줄의 대비를 실제 프레임 확인 후 보강.
- C03에 새 로컬 실내악 BGM 추가. 원본 음성은 넣지 않았으며 화면·자막만으로 이해되는 구성 유지.
- C02/C04 음악·효과음 AAC 패킷 그대로 보존. C05 -1.15dB / C06 -1.99dB 단일 음량 조정으로 음악의 개성·정적 유지.
- 목표 -23 LUFS±1 / 최대 -3dBTP 이하. 실제 결과는 각 technical_qa.json.
- C05 엔딩은 같은 원본의 동일1.75–6.75초 동작에서 재합성. 기존 자막 위에 덧씌우지 않았고 정지 이미지로 동작을 대체하지 않았습니다.

## 검수 범위

전체 디코딩·프레임수·시간축·해시·수치 음량 검증과 실제 변경 프레임을 확인했습니다. 청감이나 실시간 연속 재생의 자연스러움을 검증한 것으로 보고하지 않습니다. 실제 관객 반응과 전체 음향 청취 판단은 별도입니다.

## 재현

1. 제공된 Python 환경에서 `C03/render_c03_picture_v15.py` 실행.
2. `render_and_validate_v15.py` 실행. 다른 폴더의 기존 자료는 읽기 전용으로 참조하며 이 V15 폴더에만 씁니다.
3. `finalize_metadata_v15.py` 실행해 원본 해시와 동일 동작 프레임을 비교.

로컬 GeneralUser GS 및 기존 설치된 FFmpeg/PyAV/Pillow/tinysoundfont를 사용했습니다. Flow 추가 생성·유료 API·업로드는 없습니다.
