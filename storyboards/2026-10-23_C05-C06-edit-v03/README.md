5번의 최종 v02 영상·음원은 바이트 그대로 이 v03 납품 폴더에 복사했습니다. 6번은 v03에서 완료 모니터 지속, 노트북 표면 정리까지 반영했습니다. 과거 v01/v02 편집 영상 및 작업용 무압축 WAV는 로컬에 보존하고 Git에는 해당 버전의 코드·프레임 모음·기록을 남겼습니다. 사용자용 최신 MP4는 이 폴더의 두 파일입니다.

모든 동작 장면은 기존 Flow 원본입니다. 6번 마지막 4.75초만 별도 타이포그래픽 엔딩이며, 누락 동작을 움직이는 정지 이미지로 대신하지 않았습니다. 원본 MP4는 수정·재인코딩하지 않았습니다. 본 편집본만 파생 렌더입니다. 원본의 Veo 출처 표시는 유지했습니다.

음성이 없어도 내용을 이해하도록 모든 주요 대사는 자막으로 후처리했습니다. 원음은 전체 제외했고, 이 두 작품을 위해 새로 작곡한 로컬 악기 음원과 절차적으로 만든 효과음만 사용했습니다. 외부 곡이나 기존 C03 선율을 가져오지 않았습니다. 악기 라이브러리는 GeneralUser GS 2.0.3이며 [라이선스](GeneralUser-GS-LICENSE.txt)를 함께 보존했습니다.

검수 범위: 실제 렌더 추출 프레임의 세 명 독립·교차 검수, 수정 지적 재확인, 영상·오디오 전체 디코딩, 원본 해시 보존, 720p24fps/길이/PCM 포화/음량·피크 검사. 연속 재생·음악과 효과음 실청취·현장 재생·관객 반응은 확인하지 않았습니다. 단순 디코딩을 실청취로 간주하지 않습니다.

수용한 차이: 5번의 완전 처마 진입과 사다리 브레이크 고정은 시간 생략. 기둥 제거 전후 구도의 작은 처마 잔해 차이는 이야기 이해를 막지 않는 한계로 기록했습니다. 행사 일정·장소·성과 수치는 추가하지 않았습니다. 최종 사용자 승인이나 공개 게시를 수행한 상태는 아닙니다.

실행 재현은 `render_films.py`의 명시된 로컬 런타임·악기 경로를 사용합니다. 생성 API나 Flow 호출을 포함하지 않습니다. `build_delivery.py`는 Windows 보기용 사본과 해시를 만들고, `build_docs.py`는 저장소 진입 문서를 갱신합니다.
