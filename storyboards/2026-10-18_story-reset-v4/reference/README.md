# 참고를 적용한 범위

돌고래유괴단 작품 전체를 하나의 공식으로 보지 않았습니다. 아래 작품의 일부 화면, 공식 제작 설명, 제작자 인터뷰를 확인해 이야기 작동 방식을 비교했습니다. 전편 연속 감상이나 실제 음원 청취를 했다는 기록은 아닙니다. 작품별 정확한 확인 범위는 [조사 기록](reference_audit.json)을 따릅니다.

| 참고 작품 | 확인한 구조와 이번 적용 |
|---|---|
| [캐논 안정환의 파워무비](https://www.youtube.com/watch?v=3KuYt8feH9s) | 인물에게 기대한 이미지와 실제 선택의 충돌. 새 악마 편은 위협하는 거래자가 발표 기회를 영업하는 관계 변화로 응용. |
| [SSG 압도적 쓱케일](https://www.youtube.com/watch?v=2Zlkd3oxFI0) | 약속을 문자 그대로 과도하게 실행하는 규모. 새 환경 배송 편은 질문 하나에 작업환경 전체가 도착하고, 실패 환경까지 따라오는 사건으로 응용. |
| [배스킨라빈스 왕의 추석선물 3](https://www.youtube.com/watch?v=oHhkO4kYZOk) | 서로 다른 역할과 규칙의 충돌. 새 촬영장 편은 연출의 권한과 실제 경험자의 발언권이 충돌하도록 구성. |
| [그랑사가 연극의 왕](https://www.youtube.com/watch?v=mK8GiTBnFq0) | 도입 화면과 제작자 설명에서 배우·역할·표현 규모의 불균형을 참고. 재생 오류로 뒤 장면은 분석 근거로 삼지 않음. |

장면·고유 대사·유명인 외모·음악은 옮기지 않았습니다. 새 시간여행 편과 현장 보존 편 역시 독립적인 허구 이야기입니다. 유머의 실행 방식은 강제 귀환, 목표의 역전, 규모 확대, 역할 교체, 자기 규칙에 갇힘으로 구별했습니다. 이 비교는 기획 판단이며 관객 반응 측정이 아닙니다.
