원본은 재인코딩하지 않았다. 다운로드 파일과 보존본 SHA256 일치를 확인했다. C01 원본은 누적 5컷이며 K06·K07은 미생성이다. 완성 편집본은 아직 없다. 사용자는 크레딧 갱신을 기다려 모든 컷을 영상으로 채우는 방식을 선택했다.

K05는 기존 K02·K03의 손수건 조기 등장 문제에 대응해 미래 H2를 언급한 공통 문구를 이 컷에는 H1 하나만 있다는 명시로 바꿨다. 원문과 실제 제출본을 함께 보존한다. 기존 K01·K02·K03을 다시 생성하지 않았다.
