## 다음 실행 순서

1. 실제 잔액·진행 중·완료 영상을 확인한다. run04 종료 잔액 0은 과거 관측값이다.
2. 미생성 K06, K07부터 생성한다. 요금이 Fast20이면 두 컷에 40크레딧이 필요하다. 비용과 지원 설정은 요청 직전 UI에서 다시 확인한다.
3. K06에서 B의 H2 첫 등장을 보여주고, C는 H1을 유지한다. K07에서는 **B가 자기 H2를 접는다.** A가 접는다는 낡은 storyboards.json 문구보다 최신 edit_timeline.tsv와 전달 패키지 README의 보정을 따른다.
4. 7컷이 모두 있으면 정확한 트림·음성·연결을 검수한다. K02/K03/K04 문제를 편집으로 해결할 수 없을 때만 수정 생성하며 이유·프롬프트 차이를 기록한다. 같은 컷 하루 추가 1테이크 이내, 같은 결함 두 번 연속이면 보류한다.
5. 대사·효과음·자막을 정리해 60초 이내 별도 버전으로 렌더링한다. 원본 MP4와 원자료는 변경하지 않는다. 미해결 음성을 둔 채 완성이라 하지 않는다.

진지한 피아노·현악의 정서, 물 소리, 밀대 마찰, 오열, 행사 공개 순간의 공간음, 마지막 손잡이 소리 순으로 설계한다. 기존 레퍼런스의 음악을 복제하지 않는다. 유료 API·추가 구매는 승인 범위 밖이다.

확인한 로컬 수단: Windows System.Speech에 Microsoft Heami Desktop(한국어 여성) 음성이 설치되어 있다. 아직 음성 파일을 생성하거나 품질을 청취하지 않았다. 한국어 남성 음성은 확인되지 않았으며 여성 기본 음성으로 A·C의 감정 연기를 대체해 완성이라고 하지 않는다. 자동 한국어 음성 인식 도구도 현재 설치되지 않았다.

기존 FFmpeg는 trim/concat/overlay/amix/adelay/atempo/loudnorm/ass/subtitles/drawtext 및 H.264/AAC를 지원한다. 위치는 storyboards/2026-10-15_flow-pilot-01/.tools/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v7.1.exe. 설치 도구는 Git에 포함하지 않는다. 한글 폰트는 Windows malgun.ttf와 NotoSansKR-VF.ttf가 있다.

## 검증 한계

현재 검수는 0.5초 간격 표본과 K05 일부 원해상도 정지 프레임이다. 세 검수자가 독립 검토 후 교차 검증했다. 실제 음성 청취·연속 재생·립싱크를 검증한 것은 아니다. K05 후반 A의 흰 부분은 원해상도에서 셔츠 커프스로 확인해 새 손수건 의심을 기각했다.

기존 예약 ai-flow는 매일 00:10 한국시간에 확인하도록 유지하고 C01 완성 우선순위를 반영했다. 실제 자정 충전을 보장하지 않는다. C01 완성 후 기존 C02~C05 생성 요청을 이어간다.
