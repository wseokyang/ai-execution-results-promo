51.25초 / 1280×720 / 24fps / 1230프레임. 화면과 후처리 자막으로 내용을 전달하며, Flow 원본의 대사와 음향은 사용하지 않는다. 모든 동작은 실제 생성 MP4에서 가져왔다. 기존 완성본에 박힌 자막을 덮거나 움직이는 정지 이미지로 동작을 대신하지 않았다. 과거 편집본과 Flow 원본은 변경하지 않았다.

## 이번 구성

기둥을 뺀다 → 입구로 들어가려 한다 → 목이 걸린다 → 지붕 앞 테두리를 잡는다 → 목을 빼낸다 → 몸을 일부 돌린다 → 작업자가 잭을 가져온다 → 잠시 더 잡아 달라는 부탁을 받는다 → AI 실행 사례를 보는 상황으로 이어진다.

새 연결 장면 때문에 길이가 늘어났으며, 실패한 N04 후반은 제외하고 0.5–2.0초만 사용했다. 이어지는 작업자·잭 실제 원본의 근접 삽입 컷으로 시점을 전환한다. 이 삽입은 원본 384×216 영역을 확대했으므로 주변 화면보다 부드럽다.

**주의할 제작 판단:** 완전한 몸 회전과 동일한 손 모양으로 이어지는 연속 동작은 확보하지 못했다. 지붕 앞 테두리를 잡는 동작을 채택한 것이며, 지붕 아래에서 하중을 받는 동작을 물리적으로 검증했다고 표현하지 않는다. 작업자 삽입 전후에는 자세·손잡기 상태의 편집상 생략이 남는다. 이 버전은 인과 연결을 평가하는 검토본이며, 세 검수자의 최종 통과 결과는 총괄의 별도 기록을 따른다.

## 재현

프로젝트 루트에서 제공 런타임으로 `render_causal_edit.py`를 실행한다. 원본 SHA-256은 매니페스트에 있고 렌더 후 동일성을 확인한다. 기존 v04의 DSP 함수를 읽기 전용으로 가져오며, 이전 음악 일부와 같은 현악기 음색의 낮은 지속음을 사용한다. 새 효과음은 보이는 동작의 시점에만 둔다. 붕괴음·손 충격·보이지 않는 잭 클릭은 추가하지 않았다.

기술 검사는 전체 AV 디코딩, 1/24초 영상 PTS, 오디오 끝 시간·연속 PTS·포화 여부를 확인한다. 실제 연속 재생, 실청취, 현장 스피커와 소음 조건은 검증하지 않았다. 이미지 검토는 연락판과 연결부 추출 PNG 기준이다.

큰 PCM WAV와 검토용 개별 PNG는 재현 중간물이다. 납품 MP4와 편집 코드, 매니페스트, SRT, 검증 JSON 및 연락판을 중심으로 검수할 수 있다.
