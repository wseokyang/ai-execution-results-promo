## 수정한 핵심 제작 지시

- C01: 포스터까지 움직이지 않게 K04의 모니터 속 영상만 생성·합성. K05 수강생은 이미 서 있음. K06 착지 뒤 대사에 충분한 시간 확보.
- C02: 동일 제품·보호창·카메라를 고정. AI 후보/재촬영 결과와 마지막 증거 사진은 후편집으로 정확히 연결.
- C03: 이미 열린 방·파일과 펜 없는 손에 맞춤. 같은 조건의 근거는 표지 무늬가 아닌 내부 기록. 펜·패널 레일 소리 제거.
- C04: 병사 메모는 한 사람씩, 배식창은3개/팔6개. 지휘관의 숟가락은 별도 소유. 음식 등장 때가 아니라 첫 그릇이 창밖으로 나올 때 음악 중단.
- C05: 기둥 제거 A 다음 실제 마지막 프레임으로 몸 접기 B 시작. 사다리는 이미 펴진 상태에서 하부만 이동·고정. 기사와 화면 밖 반장 화자를 구분.

## 공통 제작 규칙

- Frames 시작 프레임만,16:9,x1,720p 제안. 사용자 선호대로 Lite부터 적합성 검토. 제출 직전 실제 UI의 모델·길이·오디오·비용·잔액 확인. Fast 자동 변경 없음.
- 권장4/6/8초는 원본 생성 길이. 본편 컷 길이와 구별한다. UI 미확인 상태이며 실제 지원값/비용 확인 후 제출. 대사와 행동을 빨리 밀어 넣지 말고 편집용 앞뒤 여유 확보.
- 문장은 정확히 한 번, 자연스러운 표준 한국어. 과한 홍보 억양·급한 말·불필요한 감탄사 금지. 비발화 인물은 입을 움직이지 않는다. 오디오는 무음 반환OFF를 확인하고 실제 결과 청취.
- Flow 요청에는 배경음악 없음. 대사와 필요한 현장음만. 의도한 정적은 후편집에서 음악 트랙만 끈다. Flow 결과에 음악이 섞이면 분리 가능 여부와 음질을 확인.
- 역할별 첫 자연스러운 채택 원음을 기준으로 다른 컷을 직접 비교. 프롬프트의 화자 묘사만으로 목소리가 고정됐다고 쓰지 않는다. ASR은 누락 점검 보조이며 청취·립싱크 검증이 아니다.
- 캐릭터 얼굴·복장·연령·체형·소품은 채택 PNG와 일치. 전후컷 상태 대조. 실제 표정/동작이 자연스럽지 않으면 상태를 기록하고 필요한 컷만 수정.
- 행사명과 AI 화면·증거 사진·조건 도식은 후편집. 미확정 날짜·장소·성과수치·참석 절차를 창작하지 않는다. 엔딩 제목은 원안5~6초 보존.
- 현재 계정 UI·잔액·가격을 확인하지 않았다. 과거 Lite10/Fast20은 현재 견적이 아니다. 44개/47개는 소스 계획 수량이며 재시도 한도가 아니다.
- BGM은 사용권이 확인된 한 곡 또는 허가된 새 음원으로 작품별 일관성을 잡는다. 특정 광고의 음원을 그대로 가져오지 않는다.
- 이 패키지는 검토·준비만. 오늘 Flow 업로드/동영상·음원 생성/크레딧사용/예약재개0. 오늘저녁이라는 말만으로 예약을 만들거나 자동 실행하지 않는다.

Google 공식 문서상 Veo 3.1 Lite/Fast의 첫 프레임 생성은4/6/8초 항목을 제공합니다. 아래 원본 길이는 편집 여유를 포함한 제안이며 실제 계정 UI를 확인해야 합니다.
