## 추천과 확인 범위

참석 독려는 **4안**, 행사 현장 도입은 **2안**을 우선 추천한다. 4안은 관객이 직접 과정에 관심을 보이는 행동으로 참석 동기를 만들고, 2안은 “처음엔, 여기서 막혔습니다”라는 실제 발표의 첫 문장으로 넘기기 쉽다. 과장된 연기와 광고 패러디를 강하게 밀면 1안이 적합하다.

모든 이미지가 첫 프레임이므로 설명의 마지막 행동을 미리 완성한 그림이 아니다. 엔딩 이미지는 글자 없는 배경판이며, 정확한 행사명은 HTML에서 별도 조판 예시로 보여 준다. 제목 가독성은 엔딩 6초를 확보하도록 설계했다. 실제 영상의 동작·음성·웃음 반응을 검증했다는 뜻은 아니다.

행사 세부 일시·장소·참석 방법·상금·성과 수치는 미확인이라 넣지 않았다. qrew의 원참고 분석문·대표 프레임·스토리보드·편집 기록을 확인했으며, 전체 영상 연속 감상이나 실제 음원 청취를 했다고 주장하지 않는다. [연구 근거](research_notes.md)에 확인 범위를 기록했다.

독립 작가 2명이 각각 4후보를 제출했고 총괄이 5안을 선정했다. 검수자 A·B·C가 같은 종합 기준으로 독립 검토한 뒤 서로의 지적을 교차 검증했다. 수정 콘티 39컷을 세 명 모두 다시 읽고 필수 지적 해결을 확인했다.
