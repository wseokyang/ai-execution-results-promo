# C01 v03 · K04 말 속도와 호흡 수정

[앞뒤 장면 포함 25초 확인본](C01_K04_context_v03_25s.mp4) · [55초 전체 검토본](C01_review_edit_v03_55s.mp4) · [합성 원본 WAV](C01_K04_D_natural_take01.wav)

사용자는 v02 음성이 상황에 맞지 않으며 구체적으로 **너무 빠르거나 기계적**이라고 답했다. 해당 음성은 미채택으로 기록했다. 이번에는 음색 참조만 하던 방식에서 벗어나 속도·호흡·억양을 직접 지시할 수 있는 로컬 합성으로 “제가 헤맨 과정도, 같이 보여드릴게요.”를 다시 만들었다.

새 합성 원본은 **3.92초**다(v02 2.48초). 재생 속도나 피치를 후처리로 바꾸지 않았다. 차분한 실무 발표자가 자기 시행착오를 동료에게 설명하는 연기를 지시했다. D까지 울지 않아야 C의 과도한 반응과 이후 발표장 공개의 대비가 유지된다. 연기 지시 검토는 `direction_review.json`에 남겼다.

Qwen3-TTS 1.7B CustomVoice의 한국어 합성 화자 Sohee를 사용했다. **K06 D를 복제한 목소리는 아니므로 음색 연결과 자연스러움은 실제 청취 판단이 남아 있다.** 이미 사용자가 자연스럽다고 확인한 K02·K06은 유지했다. 새 음성이 승인됐거나 영상 전체가 최종 완성됐다고 판정하지 않는다.

전체 편집본의 22.00~25.92초에 새 음성을 배치했다. K04의 기존 주변 소리는 유지한다. 영상 1,320개 압축 패킷과 상대 타임스탬프는 v01과 동일하다. AAC 오디오만 재인코딩했고 리먹스의 일정한 -0.9766ms 차이는 기록했다. 25초 확인본은 전체 영상 17~42초를 별도로 인코딩한 미리보기다. 이전 버전과 Flow 원본은 모두 보존했다.

검증 범위:

- 자동 전사에서 마지막 “보여드릴게요”를 포함한 문장 전체를 검출했다. 발음·연기·자연스러움 청취 검증은 아니다.
- 저장된 원본 PCM 피크는 약 0.6423, 포화 샘플 0개다. 초기 합성의 부동소수점 배열은 보존하지 않았으며 이후 재현 코드에 저장 전 유한값·피크 검사를 추가했다.
- 전체본과 확인본 모두 끝까지 디코딩했다. 음성은 K04 종료 전 1.08초의 여유를 남긴다.
- Flow 추가 생성·크레딧 사용·외부 유료 API 호출은 모두 0이다. 로컬 모델 다운로드와 CPU 합성만 수행했다.

`generate_voice.py`, `replace_voice.py`, `transcribe_voice.py`와 JSON 기록으로 재현할 수 있다. 로컬 환경은 v02의 `local_voice_requirements.txt`와 동일하다. 모델 파일은 저장소 밖의 캐시에 있으며 다운로드한 공식 리비전은 `model_source.json`에 기록했다.
