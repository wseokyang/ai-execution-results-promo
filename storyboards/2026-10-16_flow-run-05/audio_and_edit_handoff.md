# C01 편집·음성 후속 작업

run05 작업 중 독립 담당자가 기존 편집 준비·후편집 자산·로컬 도구를 읽기 전용 점검했다. 실제 음성을 청취하지 않았다.

- FFmpeg의 trim/concat/overlay/amix/adelay/atempo/loudnorm/ebur128/silencedetect/astats/subtitles/drawtext를 사용할 수 있다. 원본은 변경하지 않고 별도 편집본으로 렌더링한다.
- Windows 한국어 음성은 Heami/Heami Desktop 여성만 확인됐다. 남성 감정 연기를 대신할 로컬 음성은 확인되지 않았다. K01의 “왜… 이제야…”와 호흡은 아직 필요하다. A의 K06·K07 음성과 일치 여부를 듣고 동일 화자 더빙 범위를 판단한다.
- Windows 번들 Python과 WSL에 whisper/faster_whisper/vosk/torch는 없다. 무음 검출·음량 수치만으로 한국어 대사와 화자를 검증할 수 없다.
- K04는 화면 밖 D 대사 “제가 헤맨 과정도 같이 보여드릴게요.”가 필요하다. Heami 시안은 제작 가능하나 현재 합성·청취하지 않았다. K06 D와 목소리 일관성을 확인한 뒤 채택한다.
- 다운로드가 끝나면 원본 디코딩과 SHA256을 확인하고, 0.5초 표본 프레임을 추출하여 A/B/C 독립·교차 검수를 한다. 실제 대사·연속 재생·립싱크 검증은 별도다.
- K02 약4.5초와 K03 약4초 부분후보는 아직 확정 트림이 아니다. K03 넘침 문제는 앞부분에도 남는다. 짧게 자르면 모두 해결된다고 하지 않는다.
- K07 실제 채택 프레임을 6초 유지하고 기존 title_overlay.svg를 얹는다. 이 계획된 엔딩은 누락된 동작컷의 정지이미지 대체가 아니다.
- 최종 컷 길이에 따라 SRT·음향 타이밍을 재배치하고 60초 이내로 렌더링한다. 폰트 대체와 행사명 가독성도 실제 출력으로 검수한다.

현재 남성 감정 음성, 다운로드 원본 검수, 정확한 트림이 해결되지 않았으므로 본편 완성으로 표시하지 않는다.
