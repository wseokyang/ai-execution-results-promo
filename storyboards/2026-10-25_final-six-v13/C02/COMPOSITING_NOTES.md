# C02 V13 제작 기록

이 폴더는 「검은 점을 잡아라」의 편집 파생본만 보관한다. 모든 Flow 원본은 읽기 전용으로 사용하며 바이트 해시를 전후 비교한다.

- K03는 서로 다른 세 부품 사진에 같은 위치의 검은 점이 나타나는 원본 화면을 유지한다. ‘AI가 모은 후보 3장 / 서로 다른 사진, 같은 자리.’를 후처리 자막으로 넣는다. 전체 화면을 흰 시료로 교체하는 초안은 인과관계를 약하게 만들고 장갑 경계 문제도 있어 PD 판단으로 폐기했다.
- K04의 시험용 흰 시료는 점이 있는 상태와 없는 상태에 **동일한 표면 질감**을 쓴다. 실제 버튼 접촉 이후인 원본 5초부터 점을 지운다. K05까지 깨끗한 상태를 유지하고, 수갑 설치 이후에는 같은 표면에 흐린 고리 가림을 합성한다.
- K07의 120×80px 안팎 폰 프리뷰를 인화 크기로 확대하면 지나치게 흐려지는 문제가 있었다. PD 승인에 따라 **K08 원본 3.5초의 선명한 인화 영역 한 장**을 추출해 K07 폰 프리뷰와 K08·K09 인화에 공통 사용했다. 사진 속 모니터도 같은 고리 가림으로 맞춘다. 실제 휴대폰 촬영 원본을 복원했다는 주장이 아니라, 후반 합성으로 사진 연속성을 맞춘 선택이다. 원본 K07의 3초 셔터 암전은 유지한다.
- 인화 위 실제 손은 별도 키프레임 전경 마스크로 보존한다. 정지 이미지는 모니터·폰·인화 소품 안에만 사용하며, 인물 동작을 정지 이미지로 대체하지 않는다.
- 생성 원본의 음성과 배경음은 전부 제거한다. 새 로컬 음악과 실제 셔터 순간에 맞춘 낮은 효과음을 별도 구성한다. 기술적 오디오 검증은 실제 청취 검수와 구별한다.

`render_c02.py`는 Python, PyAV, Pillow, NumPy, OpenCV, TinySoundFont 및 로컬 GeneralUser GS 음원 라이브러리를 사용한다. OpenCV는 `.deps/`에 설치했으며 Git 납품 대상에서 제외한다. 실행 시 선택 원본을 지정한 `selected_new_clip.json`이 필요하다. 고리가 늘어나는 `C02_K05_shortchain_take01.mp4`는 코드에서 명시적으로 거부한다.

최종 선택 구간, 후처리 자막과 원본 해시는 `edit_manifest.json`, 기술 검증은 `technical_validation.json`, 실제 시각 검토 범위는 `self_review.json`에 기록한다. 이 문서 자체가 최종 검수 통과를 뜻하지 않는다.
