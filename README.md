## 환경과 보존 범위

- 설치 도구(`.tools/`)와 Python 캐시는 포함하지 않습니다. 파일럿의 `inspect_clips.py`는 Pillow·NumPy와 로컬 `.tools/`의 `imageio-ffmpeg==0.6.0`을 사용합니다.
- 프로젝트 밖의 qrew 참고 자료는 포함하지 않습니다. 기존 위치는 `/home/wooseok/wsy/motion/qrew_old`이며 읽기 전용 참고 자료입니다.
- 일부 출처 기록과 제작 스크립트에는 기존 WSL 절대 경로가 남아 있습니다. 다른 환경에서 재실행할 때 경로를 확인해야 합니다. 검토용 HTML과 제작 패키지의 상대 경로 자료는 내려받아 열 수 있습니다.
- 기존 산출물의 체크섬을 보존하기 위해 `.gitattributes`에서 자동 줄바꿈 변환을 끕니다.
- 정확한 행사 일시·장소·신청 방법 등 미확정 정보는 원자료와 최신 사용자 지시로 확인합니다.
